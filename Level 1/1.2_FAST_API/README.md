# 1.2 FAST API

This section is focused only on FastAPI.

It is designed as a structured learning path from beginner to advanced.

## Study order

1. `01_Getting_Started`
2. `02_Routing_and_Parameters`
3. `03_Request_Body_and_Validation`
4. `04_Responses_and_Error_Handling`
5. `05_Dependencies_and_Project_Structure`
6. `06_Advanced_FastAPI`
7. `07_Practice_and_Interview`

## What you will learn

* what FastAPI is and why it is popular
* how to build your first app
* routing and path/query parameters
* request body handling with Pydantic
* validation and type checking
* status codes, responses, and exception handling
* dependencies and clean project structure
* middleware, background tasks, file uploads, security ideas, and async concepts
* how FastAPI fits real GenAI backends

## How to use this folder

Each topic folder contains:

* a `README.md` for quick orientation
* one main notes file
* one `.ipynb` notebook with coding examples

## Important note

Some advanced production topics like databases, auth providers, and deployment infrastructure are introduced here from a FastAPI point of view.
They can be expanded later when you ask for those subtopics separately.
