# 1.5 Authentication Basics

This section is focused on authentication basics for backend APIs.

The goal is to understand how systems verify identity before giving access.

It is intentionally practical.
You do not need to master every security standard right now.
You need enough clarity to build safe beginner-level APIs and explain the basics in interviews.

## Study order

1. `01_What_Is_Authentication`
2. `02_Common_Auth_Methods`
3. `03_API_Keys_and_Tokens`
4. `04_Authentication_in_FastAPI`
5. `05_Auth_for_GenAI_Systems`
6. `06_Interview_and_Revision`

## What you will learn

* what authentication means
* difference between authentication and authorization
* common authentication methods used in APIs
* API keys, bearer tokens, and JWT at a basic level
* how FastAPI protects routes
* how authentication fits real GenAI systems

## Goal

After reading this section, you should be able to:

* explain authentication in simple words
* identify common auth patterns in APIs
* protect a simple FastAPI route
* understand where secrets and tokens are used
* connect authentication ideas to real AI products
