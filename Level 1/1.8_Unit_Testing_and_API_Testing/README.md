# 1.8 Unit Testing and API Testing

This section is focused on unit testing and API testing for backend applications.

The goal is to help you build confidence that your code works correctly and keeps working after changes.

Testing is one of the habits that separates quick demos from maintainable software.

## Study order

1. `01_Why_Testing_Matters`
2. `02_Unit_Testing_Basics`
3. `03_API_Testing_Basics`
4. `04_Testing_in_FastAPI`
5. `05_Testing_for_GenAI_Systems`
6. `06_Interview_and_Revision`

## What you will learn

* why testing matters
* what unit testing means
* what API testing means
* how `pytest` style tests are written at a basic level
* how FastAPI endpoints are tested
* what is different about testing GenAI systems

## Goal

After reading this section, you should be able to:

* explain the difference between unit tests and API tests
* write simple tests for Python functions
* test basic FastAPI endpoints
* think about edge cases and failure cases
* understand why GenAI systems still need testing even when outputs are probabilistic
