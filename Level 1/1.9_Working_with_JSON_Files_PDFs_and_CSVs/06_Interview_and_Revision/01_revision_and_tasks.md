# Revision and Practice Tasks

## Revision checklist

You should now be able to explain:

* what JSON is and why APIs use it
* how to read and write simple files in Python
* what CSV files are used for
* why PDFs are harder than plain text files
* how file uploads fit FastAPI
* why document handling matters in GenAI systems

## Practice tasks

### Task 1

Write a Python script that:

* creates a dictionary
* converts it to JSON text
* parses it back into Python data

### Task 2

Create a text file and write some content into it.
Then read the same file and print the content.

### Task 3

Create a small CSV file with columns such as:

* `name`
* `score`

Read it back using `csv.DictReader`.

### Task 4

Design a simple document upload flow for a GenAI backend.
Think about:

* PDF upload
* text extraction
* metadata storage
* JSON response

## Interview questions

* What is JSON?
* Why is JSON common in APIs?
* What is a CSV file?
* Why are PDFs harder to process than plain text?
* How can FastAPI accept uploaded files?
* Why is document handling important in RAG systems?

## Final note

If these ideas feel comfortable, you are becoming much more ready to build document-driven AI applications instead of only toy endpoints.
