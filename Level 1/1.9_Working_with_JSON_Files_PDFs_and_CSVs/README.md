# 1.9 Working with JSON, Files, PDFs, and CSVs

This section is focused on working with common data and document formats in backend applications.

The goal is to help you become comfortable handling the kinds of inputs and outputs that real AI backends use every day.

This topic matters because backend systems do not work with only Python variables.
They constantly read, write, transform, upload, and return structured data and files.

1. `01_Why_This_Topic_Matters`

3. `03_Working_with_Files_and_CSVs`
4. `04_Working_with_PDFs`

6. `06_Interview_and_Revision`

## What you will learn

* why common data formats matter in backend work
* how JSON is used in APIs
* how to read and write files safely
* how CSV files are handled in Python
* why PDFs need special care
* how these formats fit FastAPI and GenAI systems

## Goal

After reading this section, you should be able to:

* explain where JSON, files, CSVs, and PDFs are used
* read and write simple files in Python
* understand JSON request and response flow
* think clearly about document ingestion for AI backends
* connect file and data handling to practical backend APIs
